# Web-Based System Administrator Career Portfolio: Career Pathways

Responsive React portfolio for Joshua M. Macatol, a Bachelor of Science in
Information Technology (BSIT) student. Built with React and Vite.

The header includes a light/dark mode toggle. The selected theme is saved in
browser storage and restored on the next visit.

## Run locally in PowerShell

From the project folder, install dependencies once:

```powershell
npm.cmd install
```

Start the development server:

```powershell
npm.cmd run dev
```

Open the local URL shown in the terminal (usually `http://localhost:5173/`).
Use `npm.cmd` in PowerShell if the `npm` command is blocked by the Windows
script execution policy.

## Other commands

```powershell
npm.cmd run build
npm.cmd run preview
```

The production build is written to `dist/`.
